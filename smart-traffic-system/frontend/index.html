Upload traffic videos — get signal times

One normal video shows one road, so upload one video for each approach. The system samples frames from each video, counts the vehicles it can see (car, motorcycle, bus, truck), and then decides how many seconds of green each signal should get. Until you upload a video, the numbers below are demo numbers only.

OR — one wide video of the whole intersection

If ONE video shows all four roads at once, use this instead. Select the video, then draw one box on each road: pick the approach name, then drag on the video to draw its box. Detection runs once per frame on the full picture, and each vehicle is counted for the box it falls in. This only gives correct results if all four roads are really visible in the video.
