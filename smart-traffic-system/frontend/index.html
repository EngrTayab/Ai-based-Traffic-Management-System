Emergency & pedestrian

Emergency: give one approach an immediate priority green — the current green first ends safely (yellow, then all-red). In this prototype the button stands in for an emergency vehicle; automatic detection is future work. Pedestrian: stop all approaches for a few seconds so people can cross safely.

Live camera

Point the laptop camera at a road — or at a screen playing a traffic video. First Open camera to see the view without counting anything; in model mode fit the four coloured boxes to the roads with Auto-fit regions to roads, then press Start detection — only then does the system count the vehicles it can see, and when the counts change it recalculates the signal times by itself. One camera watches the whole table-top model at once and all four approaches are counted together — the toy cars do not need to move.

Upload traffic videos — get signal times

One normal video shows one road, so upload one video for each approach. The system samples frames from each video, counts the vehicles it can see (car, motorcycle, bus, truck), and then decides how many seconds of green each signal should get. Until you upload a video, the numbers below are demo numbers only.

OR — one wide video of the whole intersection

If ONE video shows all four roads at once, use this instead. Select the video, then draw one box on each road: pick the approach name, then drag on the video to draw its box. Detection runs once per frame on the full picture, and each vehicle is counted for the box it falls in. This only gives correct results if all four roads are really visible in the video.
